Change Log

New features, Google Photos compatibility updates, and improvements across Google Chrome and Microsoft Edge.

2026-03

Version 4.0 — Managed Download Queue, Pause/Resume & Concurrency Controls

Version 4.0 introduces a redesigned download queue engine and reliability improvements for large Google Photos albums in both Google Chrome and Microsoft Edge:

  • Managed download queue with real-time completed/total progress counter.
  • Pause and Resume buttons so large album downloads can be paused and resumed at any time.
  • Settings gear menu with a configurable 1–6 concurrent downloads slider.
  • Improved performance for large albums.
2025-03

Version 3.0.0 — Direct Google Photos Web Automation & Original Quality

Version 3.0.0 automates downloading using the Google Photos website instead of the Library API. It is a major change. Google announced in September that the Google Photos Library API would no longer allow "accessing albums and media items not uploaded by your app" after March 31. A benefit is the photos downloaded are now the original size. Also, the location data is included if it is shared with you. See how Google Photos protects your location data.

2024-02

Version 2.2.0 — Manifest V3 & Filename Sanitization

Version 2.2.0 contains a bug fix for invalid filename characters and an update to Manifest V3.

2021-08

Version 2.1 — Microsoft Edge Add-ons Launch

Album Download 2.1 is now available for Microsoft Edge.

2021-07

Version 2.0 — Stripe Subscriptions

Album Download 2.0 now available in the Chrome Web Store. Stripe is now used for payments. A link to pay is available in the app.

2021-02

Chrome Web Store disabled all new payments and has listed Album Download as "no longer available". Work to enable another payments system is not easy. See issue #25.
