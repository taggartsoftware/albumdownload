How to Start Downloading Right Now

  1. Switch back to your open Album Download browser tab.
  2. Click your browser's Reload / Refresh button (or press F5 / Ctrl+R / Cmd+R).
  3. Before your first big download, make sure "Ask where to save each file before downloading" is turned off at chrome://settings/downloads (see Support).
  4. Click Download All to save your album in exact order!
