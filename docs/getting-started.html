Getting Started

How to scan a Google Photos album, check your browser download setting, and save every photo and video in order.

How It Works

  1. Open any individual album (https://photos.google.com/album/...) or shared album (https://photos.google.com/share/...) in Google Photos. If you haven't installed the extension yet, install Album Download for Google Chrome or Microsoft Edge and pin the icon to your browser toolbar.
  2. Click the Album Download icon in your browser toolbar. Let the album tab automatically scroll from top to bottom while Album Download discovers every photo and video in order—it switches to the Album Download tab automatically as soon as scanning finishes.
  3. Preview every thumbnail and customize your Save as folder/filename pattern (default {{title}}/{{title}} {{index3}}) and optional photo dimensions (Max width, Max height, Crop).
  4. Sign in with Google (requires an active subscription) and click the cloud download button to save every photo and video into its album folder inside Downloads. (Tip: Sort the folder by Name A–Z to view files in exact album sequence.)

Before Large Downloads — Browser Setting to Check

Before downloading a large album, turn off per-file save prompts in your browser so a Save As dialog does not open for every single photo:

Google Chrome

In Chrome Settings → Downloads (chrome://settings/downloads, or click More → Download settings inside the extension), turn OFF "Ask where to save each file before downloading".

Microsoft Edge

In Microsoft Edge Settings → Downloads (edge://settings/downloads), turn OFF both "Ask me where to save each file when downloading" and "Ask me what to do with each download".
