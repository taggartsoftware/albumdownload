Question and Answers

Why am I prompted to save each file?

It is a browser setting that you can change at chrome://settings/downloads. See issue #17 for more help.

How are downloaded files named and organized into folders?

By default, "Save as" uses {{title}}/{{title}} {{index3}} so each album is downloaded into its own subfolder inside your browser's Downloads folder in sequential order (for example, Family Trip/Family Trip 001.jpg). You can edit "Save as" before downloading—for example, remove {{title}}/ to save directly into Downloads, or use {{index4}} for albums with 1,000 or more items. File extensions are added automatically.

Why is it not downloading with the folder or name in "Save as"?

A few customers have reported this issue. It is usually caused by another browser extension overriding download filenames and subfolder paths. Try disabling other download or privacy extensions, and see issue #20 for more help.

Can I use Album Download in both Google Chrome and Microsoft Edge web browsers?

Yes, a subscription allows you to use it in either web browser. If you are having problems with Album Download in one web browser, please try the other.
